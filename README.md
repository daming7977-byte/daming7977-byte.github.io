# Ming Li — Academic Website

A lightweight, responsive academic homepage designed for GitHub Pages.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish on GitHub Pages

1. Create a repository named `<username>.github.io`.
2. Upload these files to the repository root and push to `main`.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

For an existing project repository, the same files can be deployed from that repository and Pages will publish at `<username>.github.io/<repository>`.
